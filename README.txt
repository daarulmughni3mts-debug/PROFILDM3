WEBSITE PROFIL PONDOK PESANTREN DAARUL MUGHNI AL MAALIKI 3

ISI FOLDER: index.html | css/style.css | js/data.js | js/app.js | images/

CARA ONLINE: upload seluruh isi folder ke hosting (cPanel public_html), Netlify, Vercel, atau GitHub Pages. Buka index.html.

MODE ADMIN: scroll ke paling bawah, klik "Admin". Password awal: admin123 (segera ganti lewat tombol "Ganti Password").
- Klik teks untuk mengedit. Klik foto untuk mengganti (unggah atau URL/path).
- Tombol "+ Tambah" dan "x" untuk menambah/mengurangi ustadz, ustadzah, kelas, foto.
- Kelas dipisah: Kelas Putra (wali kelas Ustadz) dan Kelas Putri (wali kelas Ustadzah). Klik angka untuk mengubah jumlah santri; "+ Tambah Kelas Putra/Putri" untuk menambah kelas.
- Tombol "Edit link": video YouTube, PPDB PPDM3, WhatsApp/telepon, Facebook, TikTok, Instagram, peta.

PENTING: perubahan tersimpan di browser admin. Agar tampil untuk semua pengunjung, klik "Ekspor data.js" lalu timpa js/data.js di hosting.
Tips: untuk foto banyak, simpan di folder images/ dan isi path "images/nama.jpg" agar data.js ringan.
